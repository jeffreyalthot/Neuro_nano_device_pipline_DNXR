# Conditions d’utilisation (référence R&D simulée)

Ce dépôt fournit **uniquement une simulation logicielle de recherche**.
Aucune partie n’est destinée à un usage médical, biologique, neurologique ou clinique réel.

En utilisant ce code, vous acceptez que :
1. ce projet est démonstratif et conceptuel ;
2. les modules “nano-device” et “neural nodes” sont abstraits ;
3. toute expérimentation réelle nécessiterait validation réglementaire, éthique et clinique indépendante ;
4. les contributeurs n’assument aucune responsabilité pour un usage hors simulation.
