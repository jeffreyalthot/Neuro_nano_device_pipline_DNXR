# ISO 14971 Risk Management File

Initial hazards: seizure, photosensitivity, panic, dissociation, cybersickness, vestibular nausea, loss of consciousness, excessive stimulus, persistent hallucination, memory disturbance, cardiorespiratory dysregulation, compulsion/addiction loop, neural privacy breach, replayed command, corrupt calibration, and locked-in/no-stop state.

Each hazard must trace to requirements, software controls, verification tests, residual risk, medical decision, and signed evidence before escalation beyond bench use.

## Version 0.4.9 — Clinical Lockdown + Real Evidence Gate

Human use remains blocked until signed evidence exists for physical HIL, preclinical safety, risk control verification, clinical protocol, REB/IRB approval, Health Canada ITA or FDA IDE authorization, and independent medical signoff.
