# Intended Use

This software is intended only for simulation, bench/HIL preparation, traceability, and preclinical review planning. It is not intended to diagnose, treat, monitor, stimulate, immerse, or test human subjects.

Contraindications for any future protocol draft include epilepsy/photosensitivity, severe dissociation, active psychosis, unstable cardiorespiratory status, severe vestibular disorder, incompatible implants, uncertain consent, and unknown pregnancy risk.
