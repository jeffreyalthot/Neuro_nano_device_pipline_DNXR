# Hil Latency Report Template

This document defines non-human preclinical HIL objectives for signal emulation, stimulus load, latency instrumentation, phantom profile, fault injection, emergency stop, recovery, and HIL evidence reports. Scenarios include signal loss, extreme noise, calibration drift, vestibular overload, rejected stimulus, stale watchdog subsystem, latency overrun, emergency stop, replay attack, packet corruption, phantom disconnect, timing jitter, and full-dive desynchronization.

Acceptance requires measured latency, safety response, recovery evidence, and an artifact recorded in qms/generated/.
