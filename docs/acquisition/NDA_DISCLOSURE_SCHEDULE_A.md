# NDA Disclosure Schedule A

> Confidentiality: Level 3 — NDA controlled unless otherwise stated.
> Status: Due diligence scaffold for preclinical R&D software evidence.
> Boundary: Preclinical R&D software evidence package; simulation/HIL readiness scaffold; not authorized for human use; not clinically validated; not a certified medical device.


## Covered materials
- Source code, build scripts, tests, generated QMS artifacts, validation evidence, security reviews, SBOMs, archived versions, written responses, demonstrations, USB/offline transfer media, and post-disclosure additions.

## Disclosure levels
| Level | Disclosure class | Examples | Gate |
| --- | --- | --- | --- |
| Level 0 | Non-confidential summary | public overview, non-sensitive counts | No NDA |
| Level 1 | High-level architecture | module diagrams without implementation | Mutual NDA recommended |
| Level 2 | Partial technical dossier | selected QMS, risk, requirements, traceability | Executed NDA |
| Level 3 | Full technical package | full source, tests, evidence, build logs | Executed NDA plus data-room logging |
| Level 4 | IP/commercial/chain-of-title | valuation, assignments, negotiation data | Executed NDA plus need-to-know approval |

## Human-use evidence boundary
Human-use or clinical-trial activation remains unlockable only through the documented QMS and regulatory evidence gates. This schedule does not authorize human use.
