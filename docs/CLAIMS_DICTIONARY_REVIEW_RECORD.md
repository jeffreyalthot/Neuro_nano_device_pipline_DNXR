# Claims Dictionary Review Record

> Confidentiality: Level 3 — NDA controlled unless otherwise stated.
> Evidence boundary: preclinical R&D software evidence only; simulation/HIL/hardware-bench readiness does not establish clinical safety, effectiveness, certification, or authorization for human use.


## Approved claims
| Claim | Required qualifier |
| --- | --- |
| Preclinical R&D software evidence package | Must state not authorized for human use |
| Simulation/HIL readiness scaffold | Must distinguish from clinical validation |
| Medical/regulatory review package | Must state external independent review remains required |
| Controlled hardware-bench no-human pathway | Must state no human subject and no clinical authorization |

## Blocked claims unless independently evidenced and authorized
| Claim | Required evidence before use |
| --- | --- |
| Safe for humans | Clinical evidence, regulatory authorization, medical approval |
| Clinically ready | Approved protocol, ethics review, regulator authorization, monitoring plan |
| Implant-ready | Device verification/validation, biocompatibility/safety evidence, regulatory clearance |
| Certified/approved medical device | Applicable regulator certification/clearance/license |
| Validated on real patients | Controlled clinical data and approvals |
