# Full Dive Theoretical Model

Specifies the acquisition -> signal -> inference -> calibration -> immersion -> safety -> full-dive -> render -> stimulus loop and the multisensory model boundaries.

## Required evidence criteria
- Visual, auditory, haptic, proprioceptive, and vestibular coverage are scored independently.
- Motor prediction, reality anchor, emergency exit, decompression, cognitive reversibility, temporal coherence, calibration stability, and sensory exposure control require linked tests.
- HIL-validated full dive requires HIL fault injection, latency, emergency stop, recovery, and evidence artifacts.
- Clinical full dive requires reviewed protocol readiness and Canada/US pathway documentation.
