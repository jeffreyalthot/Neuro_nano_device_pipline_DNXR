# Regulatory & Quality Implementation Plan (Simulation-to-Clinical Readiness)

> Date: 2026-05-17
> Scope: preparatory framework only (non-clinical build)

## 1) Applicable standards baseline
- IEC 62304 (software lifecycle)
- ISO 14971 (risk management)
- ISO 13485 (QMS)
- IEC 62366-1 (usability engineering)
- IEC 81001-5-1 / FDA cybersecurity guidance (security lifecycle)

## 2) Mandatory work products to establish
1. Software Development Plan (SDP)
2. Software Requirements Specification (SRS)
3. Software Architecture Description (SAD)
4. Risk Management Plan + Risk File (ISO 14971)
5. Verification & Validation Plan (VVP)
6. Traceability Matrix (Req -> Risk controls -> Tests -> Evidence)
7. Configuration Management Plan
8. Problem Resolution / CAPA workflow
9. Clinical Evaluation & Investigational protocol (external governance)

## 3) Release gates (Go/No-Go)
- Gate A: Requirements baselined, hazards identified, severity/probability matrix approved.
- Gate B: Unit/integration/system verification complete with objective evidence.
- Gate C: Cybersecurity threat model + penetration evidence + SBOM.
- Gate D: Independent QA sign-off + design review + residual risk acceptance.
- Gate E: Regulatory dossier package complete for authority submission.

## 4) Roles and responsibilities
- Quality Lead: process ownership, SOP conformance.
- Safety Officer: hazard analysis, residual risk acceptance board.
- Verification Lead: protocol execution + evidence integrity.
- Clinical Liaison: IRB/ethics/regulatory coordination.
- Security Lead: threat model, vulnerability mgmt, disclosure policy.

## 5) Current repository status
Current status remains R&D simulation. This plan defines preparatory artifacts only and does not grant clinical authorization.
