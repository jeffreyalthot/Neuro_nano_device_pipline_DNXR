# US Device Software Evidence Map

> Confidentiality: Level 3 — NDA controlled unless otherwise stated.
> Evidence boundary: preclinical R&D software evidence only; simulation/HIL/hardware-bench readiness does not establish clinical safety, effectiveness, certification, or authorization for human use.


| Evidence area | Repository artifact | Diligence disposition |
| --- | --- | --- |
| Intended use and claims | Claims dictionary, evidence boundary memo | Preclinical only; unsupported clinical claims blocked |
| Architecture/design | Architecture docs and runtime modules | Review-ready, requires independent assessment |
| Requirements/traceability | Traceability matrices and QMS checks | Internal traceability checks pass |
| Verification/validation | Unit/CTest/HIL reports | Full current run logs to attach |
| Risk management | Risk registers and safety case records | Open risks remain visible |
| Cybersecurity | Attack surface, SBOM, vulnerability registers | Tool-backed scans/SBOM pending |
| Human factors/clinical | Clinical gap and lock verification records | Not authorized; external clinical package required |
