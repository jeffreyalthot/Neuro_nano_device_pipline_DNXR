# Device Classification Rationale — Canada

The project must be conservatively treated as a high-risk investigational medical device software/neuro-interface candidate if any human testing is proposed. Human testing requires investigational testing authorization, REB approval, manufacturer/importer accountability, risk management, and clinical investigation controls.

## Version 0.4.9 — Clinical Lockdown + Real Evidence Gate

Human use remains blocked until signed evidence exists for physical HIL, preclinical safety, risk control verification, clinical protocol, REB/IRB approval, Health Canada ITA or FDA IDE authorization, and independent medical signoff.
